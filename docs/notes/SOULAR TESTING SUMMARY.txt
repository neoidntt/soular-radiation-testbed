Flowchart:

1. Teensy accepts the command to start writing

2. Teensy loads the memory with data

3. Teensy accepts the command to start reading

4. Teensy reads the entire memory. If incorrect data is read, then the error count is incremented and the Teensy sends a message to the laptop

5. Error, if no error it keeps looping until it gets an error (Continuous loop)

6. Teensy sends message to laptop. Laptop receives error
