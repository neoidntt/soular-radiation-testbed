# Legacy code (old versions)

Everything here is **superseded**. It is kept for history and to show how the project evolved. For the final code
see [`../current/`](../current/).

| Folder | Era | What changed later |
|---|---|---|
| `firmware/early-prototypes/` | Early 2026 | Arduino LCD/LED SEU simulators, replaced by the Teensy 4.1 testbed. |
| `firmware/teensy-serial-versions/` | April 2026 | Intermediate Teensy sketches (Flash + FRAM, masking, Serial4 variants), replaced by the 2026-05-01 final firmware. |
| `software/memory-test-monitor-2026-04-30/` | 2026-04-30 | Monitor GUI before the final 5/1 revision. |
| `software/curve-fitting-drive/` | Summer-Fall 2025 | First Weibull scripts (`curvefit.py`, `curvefit2.py`) with tables and write-ups, replaced by `current/software/curve-fitting/`. |
| `software/math-graphing/` | Jan-Feb 2026 | Scatter-plot experiments that led to curve fitting. |
